Pengaturan & Backup

Dashboard ini berjalan di iPhone, Android, dan PC tanpa library grafik eksternal. Grafik dibuat langsung menggunakan SVG.

Data baru tersimpan pada browser perangkat ini. Data tidak otomatis tersinkron ke perangkat lain. Gunakan Ekspor CSV untuk membuat cadangan atau memindahkan data.

Jika file dibuka melalui pratinjau Files iPhone, grafik awal tetap tersedia, tetapi fungsi input data mungkin dibatasi. Untuk pengalaman penuh, unggah file ke hosting HTTPS lalu buka di Safari atau Chrome.

Personalisasi Dashboard

Ubah nama indikator dan nama tampilan HUB. Perubahan langsung diterapkan ke judul, kartu KPI, grafik, tabel, laporan, dan ekspor CSV. Angka operasional tidak berubah.
